# HMCTS Dev Test Backend
REST API for task management (CRUD). Data is stored in PostgreSQL via Spring Data JPA.

**Base URL:** `http://localhost:4000`

## Prerequisites
- Java 21
- PostgreSQL (local or Docker)
- Gradle (wrapper included)
-
## Environment variables
|  Variable      | Description       | Example     |
|----------------|-------------------|-------------|
| `DB_HOST`      | Database host     | `localhost` |
| `DB_PORT`      | Database port     | `5432`      |
| `DB_NAME`      | Database name     | `hmcts_dev` |
| `DB_USER_NAME` | Database user     | `postgres`  |
| `DB_PASSWORD`  | Database password | `postgres`  |

Ensure the `task` table exists and matches the `Task` entity (`id`, `title`, `description`, `status`, `due_date`).

## Running the application
You will need to configure the environmental variables in your IDE in order to be able to deploy the application.
The DB_HOSTDB_PORT, DB_NAME, DB_USER_NAME and DB_PASSWORD must be present as environmental variables and correct so the
application is able to access the PostgresSQL database.

## Testing the application
./gradlew test
./gradlew integration

## API Endpoints Documentation
All API endpoints are documented by Swagger UI: http://localhost:4000/swagger-ui.html

### Task model (TaskDTO)
| Field	      | Type               | Required | Notes                             |
|-------------|--------------------|----------|-----------------------------------|
| id          | UUID               | No       | Generated by the server on create |
| title       | string             | Yes      | Max 200 characters                |
| description | string             | No       | Max 2000 characters               |
| status      | string             | Yes      | OPEN, IN_PROGRESS, or DONE        |
| dueDate     | ISO-8601 datetime  | No       | e.g. 2026-06-10T17:00:00          |


### API endpoints

| Method	  | Path                                          | Description   | Success            |
|----------|-----------------------------------------------|---------------|--------------------|
| GET      | /api/tasks/list                               | No            | 200 — JSON object  |
| GET      | /api/tasks/{id}                               | Yes           | 200 — JSON object  |
| POST     | /api/tasks                                    | No            | 201 — created task |
| PUT      | /api/tasks/{id}                               | Yes           | 200 — updated task |
| POST     | /api/tasks/{id}/status-update?status={status} | No            | 200                |
| DELETE   | /api/tasks/{id}/delete                        | Delete a task | 200                |

## Database configuration
You need a single user account with the correct permissions and you need a single table for this application to work

| Column name | Column type  |
|-------------|--------------|
| id          | uuid         |
| title       | varchar(255) |
| description | text         |
| status      | varchar(255) |
| due_date    | timestamp    |
